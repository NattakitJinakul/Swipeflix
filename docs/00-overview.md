## แนวคิดแอป

**Swipeflix** = "หนังคืนนี้ดูอะไรดี" แก้ปัญหา *choice paralysis* — เลื่อนดู Netflix 30 นาทีแต่ยังเลือกหนังไม่ได้

กลไกหลัก: **ปัดการ์ดหนังแบบ Tinder**
- ปัดขวา = ชอบ (เก็บเข้า watchlist)
- ปัดซ้าย = ผ่าน
- ปุ่มพิเศษ = เคยดูแล้ว
- แตะการ์ด = ดูรายละเอียด + trailer + ช่องทางดู

## ทำไมเลือก TMDB

| เหตุผล | รายละเอียด |
|--------|-----------|
| ฟรี + key ง่าย | สมัครได้ทันที ไม่มีค่าใช้จ่าย |
| รูปสวย | โปสเตอร์/backdrop ความละเอียดสูง — ทำให้แอป "VERY NICE" ได้ง่าย |
| ข้อมูลครบ | นักแสดง, ผู้กำกับ, เรื่องย่อ, เรตติ้ง, trailer, หนังที่เกี่ยวข้อง |
| Watch Providers | บอกว่าดูได้ที่ค่ายไหน (Netflix/Prime/Disney+) — ต่อยอด **affiliate** ได้ |
| Docs ดี | endpoint ชัด, ตัวอย่างเยอะ |

## เป้าหมายความสำเร็จ (Success Criteria)

1. ปัดการ์ดได้ลื่น 60fps (ใช้ Reanimated 4 บน UI thread)
2. ข้อมูล like/watched อยู่ถาวร (ปิด-เปิดแอปแล้วไม่หาย)
3. หน้า detail แสดงข้อมูลครบตามสเปก + เล่น trailer ได้
4. มีปุ่มพาไปสมัคร/ดูที่ค่าย streaming (affiliate)
5. UI สวยระดับพรีเซนต์อาจารย์ได้ — มี empty state, loading, haptic feedback
